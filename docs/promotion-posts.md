## 一、酷安推文（短平快 · 痛点向）

**标题建议（三选一）：**
1. 《最近大家都在防着 SystemHelper 偷传数据？我开源了个免 Root 的“联网守门员”，每个 App 联网前都得先问我》
2. 《受够了 App 后台偷跑和广告追踪？我写了个颜值在线的免 Root 安卓防火墙，还能和代理共存》
3. 《5.6MB 免 Root，安卓终于也有类似 Little Snitch 的体验了：应用首次联网先弹窗问你》

**正文：**

最近大家应该都被各种系统组件（比如 SystemHelper 类服务）或流氓 App 后台静默联网、疑似上传数据的新闻搞得很焦虑。

但系统自带的“联网控制”实在太粗暴了：只能按 WLAN/流量一刀切，根本不知道它到底连了哪个域名、哪个 IP，更做不到“发现新连接时先拦住问我”。

所以我做并开源了 **PocketGate** —— **免 Root、不到 6MB**，核心理念只有一句话：**每个应用第一次联网，都先问你。**

### 它能帮你干什么？

1. **联网那一刻，浮窗先问你**
   新装的 App 或某个系统组件突然想连外网？先拦下来，直接在当前界面弹出小卡片问你：允许、拒绝，还是**“仅此一次（离开应用自动收回）”**。同一应用的多条连接会自动合并，不会弹窗轰炸。
2. **让系统组件和后台流氓无所遁形**
   实时连接列表 + 拦截日志，哪个包名、连向哪个域名/IP/端口、是拦截还是放行，看得一清二楚，支持一键直接中断活跃连接。
3. **和 Clash / FlClash / v2rayNG 和平共处（痛点解决！）**
   传统免 Root 防火墙基于 VPN，一开就会把代理软件挤掉线。PocketGate 提供两种引擎：
   - **黑洞模式（默认）**：被拒绝的应用进 VPN 丢弃，被允许的应用不走隧道，极致省电；
   - **逐连接模式**：通过本机 `hev-socks5-tunnel` 转发，支持**精确到域名/IP/端口/QUIC 判决**，还能直接把出口指向你本地代理的 SOCKS5 端口，防火墙 + 代理一步到位。
4. **自带广告与追踪器拦截**
   内置 7 份公开拦截清单（支持自定义订阅），在本地就能拦截常见广告 SDK 与追踪域名。
5. **高颜值 & 细节拉满**
   - 原生 Kotlin + Compose 打造，**6 套主题**（黑曜石、极简霜白、极光流光、纯黑省电、系统取色等）自动跟随深浅色；
   - 自带**状态栏原生网速图标、灵动岛风格实时悬浮速度、4 款桌面小组件、控制中心磁贴**；
   - **Android 16 实时活动（Live Updates）** 支持；
   - **专注模式**（只留白名单应用联网）、**锁屏断网**、**应用锁**、**WebDAV 端到端加密同步**。
6. **真正的“绝对本地化”**
   GPL-2.0 完全开源，**无账号、无统计 SDK、不收集任何数据**。如果你连检查更新都不放心，设置里直接打开**「纯离线模式」**，PocketGate 自己也一字节都不会往外发。

（顺带一提，配套的 **Windows 版** 也在同步推进，同样是先阻断再询问的体验。）

## 二、少数派投稿（深度体验 · 产品思考向）

**标题建议（二选一）：**
1. 《在隐私焦虑时代拿回“知情权”：我如何从零设计开源防火墙 PocketGate》
2. 《免 Root 管住安卓每一条出站连接：开源防火墙 PocketGate 的设计与实战》

**正文：**

### 为什么我们还需要一层“出站防火墙”？

前段时间，“SystemHelper 等系统服务后台联网上传数据”的讨论再次把移动端隐私推上了风口浪尖。其实不止系统组件，我们手机里日常使用的各类应用，后台静默上报、接入十几个广告与追踪 SDK 早已是常态。

大多数系统的权限管理只停留在“允许/禁止使用网络”的粗粒度开关上，而传统防火墙主要防范**入站**攻击，几乎从不过问应用要**往外连向哪里**。

在 macOS 上有著名的 Little Snitch，但到了 Android 和 Windows 上，要么工具过于硬核陈旧、缺少现代交互，要么必须 Root，要么和日常使用的网络代理工具互斥。于是我决定自己写一个：**PocketGate**——一款面向普通玩家与极客的跨平台（Android / Windows）开源联网控制工具。

### 核心设计原则：先问、看得见、只在本机

在设计 PocketGate 的第一天，我就定下了三条原则：

1. **先问再放行（Prompt on First Connect）**
   在默认的「询问模式」下，没有命中规则的应用首次尝试联网时会被暂时挂起，并在当前界面上方弹出轻量询问卡片（如果位于锁屏界面，则改为可交互通知）。
   你可以选择永久放行/拒绝，也可以选择**“仅本次使用允许”**（离开应用自动收回）或**“限时放行”**——对于那些只偶尔需要用一下、平时不想让它后台常驻联网的应用，这个选项非常实用。

2. **黑洞模式与逐连接模式：在省电与精细控制之间做取舍**
   免 Root 方案绕不开 Android 的 `VpnService`，但为了兼顾续航与控制粒度，PocketGate 提供了两套引擎切换：
   - **黑洞模式（默认）**：利用 VPN 路由的反向分流特性，**只把被拒绝的应用流量接管并丢弃**，已允许的应用完全直连不经过应用本身，几乎零额外耗电。
   - **逐连接模式**：通过内置的 `hev-socks5-tunnel` 接管全部连接，实现**精确到域名、IP、端口甚至 QUIC 协议**的实时判决与实时连接列表（支持一键双向 RST 强制中断）。更重要的是，它的出口可以对接你本机运行的第三方代理（如 FlClash、Clash Meta、v2rayNG 等）的 SOCKS5 端口，彻底解决“开了防火墙就用不了代理”的冲突。

3. **把所有数据留在本地**
   安全工具的生命线是信任。PocketGate 基于 GPL-2.0 协议完全开源，没有账号系统，没有任何第三方统计或分析 SDK。所有规则与日志均保存在本地；如果你需要多设备备份，WebDAV 同步会在本地先完成 `PBKDF2 + AES-256-GCM` 加密再上传。如果希望做到极致，只需在设置中开启**「纯离线模式」**，连应用自身的更新检查和规则清单下载也会一并禁用。

### 不止于拦截：一些顺手好用的日常细节

做工具软件最怕做成“只有参数没有体验”的极客玩具，所以我们在 Android 版（Kotlin + Jetpack Compose，安装包约 5.6 MB）上打磨了不少日常细节：

- **可观测性与 Bento 仪表盘**：实时网速波形、各应用流量排行、7 份内置公开广告/追踪器拦截清单（支持自定义订阅），异常域名一目了然。
- **状态栏原生网速与灵动岛**：无需额外装测速插件，直接提供状态栏实时网速图标、悬浮灵动岛，以及 Android 16 实时活动通知（Live Updates）。
- **场景化自动化**：支持**专注模式与时间表**（工作/学习时段只放行指定白名单）、**锁屏断网**、**按 Wi-Fi SSID / SIM 卡自动切换配置规则**、**应用锁**（修改规则前校验系统锁屏），以及 **4 款桌面小组件**和**快捷设置磁贴**。
- **6 套视觉主题**：黑曜石极客、经典、极简霜白、极光流光、纯黑省电与 Android 12+ 系统取色，跟随系统深浅色自动切换。
