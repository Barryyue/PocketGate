NetworkControl {{VERSION}} — 測試版（Windows 10 / 11）
===========================================================

按應用程式控制聯網：程式第一次連網時彈窗詢問「允許 / 拒絕」，並按你的選擇生成規則。

【安裝】
1. 解壓整個壓縮包（不要在壓縮軟體裡直接執行）。
2. 雙擊 install.cmd，在「使用者帳戶控制」中選「是」。
   - 若出現「Windows 已保護您的電腦」，點「其他資訊」→「仍要執行」（測試版沒有數位簽章）。
3. 安裝完成後右下角托盤會出現 NetworkControl 圖示，之後每次登入都會自動啟動。
   程式安裝在 C:\Program Files\NetworkControl，規則和記錄保存在 C:\ProgramData\NetworkControl。

【使用須知】
- 預設是「詢問」模式：新程式連網時先被攔下並彈窗，選「允許」後程式重試即可連上
  （部分程式需要重新整理或重新開啟）。
- 介面沒有執行時，新程式的連線會被拒絕。若誤關了介面，從開始功能表重新開啟 NetworkControl。
- 托盤選單可以切換模式、暫時全部放行（勿擾）、或「完全結束」（停止攔截）。

【網路出問題時】
- 托盤選單選「完全結束」即可立刻恢復網路；或執行 uninstall.cmd 卸載。
- 即使服務崩潰，攔截規則也會由系統自動移除，不會長時間斷網。

【回報問題】
雙擊 export-diagnostics.cmd（安裝目錄 C:\Program Files\NetworkControl 中也有一份），
桌面會生成 NetworkControl-diagnostics-日期.zip，把這個檔案發給開發者即可。
也可以在介面的「設定 → 診斷」中匯出，並選擇是否包含連線記錄。
診斷包中的使用者名稱和電腦名稱已被替換，不會自動上傳任何內容。

【卸載】
雙擊 uninstall.cmd。規則和記錄預設保留；如需一併刪除，卸載後刪除 C:\ProgramData\NetworkControl 資料夾。
